# TicketSystem Mobile PoC

Mobile-first prototype for ticket creation, photo documentation and admin overview.

## Included
- Responsive mobile UI
- Ticket list
- Create-ticket flow
- Device camera/gallery input
- Photo preview and multiple photos
- Admin dashboard prototype
- PWA manifest

## Run
Serve this directory with a local static web server. Camera/PWA features require a secure context (HTTPS or localhost).

## Next step
Connect the UI to the existing ASP.NET Core API and replace local prototype state with authenticated ticket/attachment services.
